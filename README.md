# Project 1 B: Custom API Integration

This is a starter template for a Custom API Integration project using Node.js and Express. It connects to a public API (the Official Joke API) and returns formatted data.

## Prerequisites
- Node.js installed on your system

## Setup
1. Open a terminal in this directory.
2. Run `npm install` to install dependencies.

## Running the Server
- To start the server: `npm start`
- For development with auto-reload: `npm run dev`

## Endpoints
- `GET /health` - Checks if the server is running.
- `GET /api/joke` - Fetches a random joke from the external API and returns it in a customized format.

## Customization
You can edit `index.js` to change the external API to anything you like (e.g., Weather, GitHub, Movies) and process the data as required for your project.
